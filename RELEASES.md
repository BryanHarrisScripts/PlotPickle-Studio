## Future archival procedure

1. Update and publish inside Plugin Creator, retaining its new release ID.
2. Verify that Plugin Creator reports the intended version as current and perform a brief in-chat feature readback as appropriate.
3. Commit the authorized public source snapshot to GitHub with a message such as `archive: PlotPickle Studio vX.Y.Z (Plugin Creator release ID)`.
4. Record the release ID, archive commit, any omissions and the verification scope here. For skipped historical commits, identify the newer cumulative snapshot without mislabelling it a historical exact copy.
5. No GitHub Actions, CI runs, GitHub tests, required checks or PRs are part of this procedure.

GitHub commits are historical references. The Plugin Creator published release is authoritative; a GitHub change cannot publish or change the plugin.
