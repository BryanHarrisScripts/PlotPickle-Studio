# PlotPickle Story Flow — source-pinned handoff contract v1

One story and revision; four creative stages; no automatic factory. Concept-only work is permitted without native PPF, but cannot be described as saved canonical state.

| Stage | Input | Permitted draft output | Complete requires |
|---|---|---|---|
| Script | Author text or source passages | Scene/beat outline | Actual authored text and review |
| Storyboard | Script passages and scoped canonical addresses | Shot list/prompts | Valid passage-to-shot provenance |
| Visuals | Plan and character/world constraints | Image candidates | Real media bytes/hash and separate native Save/Lock truth |
| Produce | Selected source-revision media | Animatic, fal motion brief or draft film | Real verified MP4 bytes, duration, frames, hash; separate review |

Canonical layout: 4 Acts, 12 Sequences, 24 Blocks, 96 Mini-Blocks; a Mini-Block can hold 25 positions. At 24fps a nominal 3-second shot = 72 frames. One span is 1–5 contiguous positions within the same Mini-Block, for 3–15 seconds of editorial footage. This structure does not assert fal's native generation duration or a completed 2,400-shot film.

Keep project ID, revision, raw source SHA, passage IDs, shot address, asset ID and verified media hashes. Missing/unsafe assets, stale source, corrupted hash, absent native save/lock or unreviewed imagery block production readiness. A provider reference is not verified output. fal must be connected via the separate authorized ChatGPT tool, checked live and approved for each chargeable clip; unavailable or exhausted account leaves only a no-spend draft brief. No media result auto-accepts the story. Reports, Assets and Pitch Deck are read-only projections unless separately authorized.

A conversation like “Continue The Third Bell” should return one evidence-based next step without imposing GitHub, service managers, a permanent screen or repeated questions. Never mutate unrequested unrelated scenes or run paid work automatically.
