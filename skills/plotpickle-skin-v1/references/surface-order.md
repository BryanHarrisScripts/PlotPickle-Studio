# PlotPickle Studio Skin V1 — Fixed approved surface order (v0.8.38)

Style: premium matte black, off-white typography, restrained purple emphasis, small/medium consistent corners, four-pixel rhythm. All designs retain a single PLOTPICKLE STUDIO header, optional source pin, breadcrumbs and back, content area, and truthful status footer. Native controls where supported; otherwise same text order. No private story data bundled.

HOME: Brand → HOME breadcrumb → “What will you create today?” → exactly four equally weighted cards (Meet Elara / Learn / Storyboard / Connected Services) → Continue Creating only with verified story → footer.

STORYBOARD: Brand → HOME / STORYBOARD → “Storyboard: Choose how to tell your story.” → two equal REEL / ONCE cards → selected-path contextual description → Your Stories (verified only) → quiet Create a story → footer.

STORY_MAP: Brand → story pin + HOME / STORYBOARD / REEL or ONCE / STORY MAP → “Story Map” → horizontal I/II/III/IV Act rail → three sequence groups each holding exactly two globally numbered Block cards → selected Block summary → Mini 01/02/03/04 → status footer. On mobile stack Sequence and Block cards, not the Act rail.

MINI_BLOCK_SHOT_GRID: Brand → story pin + breadcrumb → block title → Mini 01/02/03/04 → counts from real source evidence → 5×5 shot positions 01–25 → legend → selected shot inspector tabs: Script / Beat / Prompt / Image / Continuity / Save-Lock → status footer. Planned slots are not media.

IMAGE_REVIEW: Brand → story pin + breadcrumb → shot title, camera/time → large actual selected image or clear absent-image placeholder → candidate variation strip → four separate statuses: Human Approved / PPF Saved / PPF Locked / Media Verified → Script / Prompt / Continuity / Audit evidence tabs → optional mutation controls only when backed by actual guarded tool actions → footer.

SAVE_LOCK_TRANSACTIONS: *Approved design gate only*: Inspect → Approve exact image → Save guarded write → Save readback → Lock guarded write → Lock readback and receipt. Additional Unlock and Regenerate require prior state/creator direction. Never imply design approval activates operations.

Not approved in this release: Production Handoff Skin V1, Connected Services Skin V1, media editor Skin V1, all other pending surfaces. Preserve their current capabilities; do not label them locked designs.

REEL_WORKSPACE_ENTRY (nested, owner-approved): Brand → HOME / STORYBOARD / REEL → REEL / “From screenplay to screen” → New Idea, Import Script, Continue Film, Explore Tools → verified Your Stories → Script/Storyboard/Visuals/Produce → footer.

MOBILE_STORYBOARD_REVIEW (nested, owner-approved): Brand/breadcrumb → verified story/shot pin → truthful counts → Mini 01–04 → 5×5 position grid → real image and source inspector → Script/Beat/Prompt/Image/Continuity/Save-Lock → four independent statuses → action placement (only operational if real guarded writes) → optional verified five-page graphic-novel edition link → footer. No hosted sidebar.

Five-panel reading: 25 shot positions per Mini-Block in exactly five pages of five. A full 24-Block structural plan has 96 Mini-Blocks and 480 potential graphic-novel pages, NOT proof that those pages exist. Preserve stored pages in the creator's private story Library.
