# Learn extension: Animation and Motion
Proposed material for mapping into the existing curriculum; do not replace or renumber existing lessons without inspecting them.
Lessons: physical weight; anticipation; visual staging; key poses; follow-through; acceleration; arcs; secondary action; timing; genre and exaggeration; spatial consistency; character appeal. For each: explain the principle in plain language, demonstrate using a fictional or user-approved shot, offer a simple practice exercise, and review the user's choices. Adapt difficulty to the learner.
Conversational triggers: Animation (teach), MotionBrief (plan), MotionReview (review), Emotion (performance), Continuity (compare), Director (creative guidance). Existing command meanings take precedence; verify routing before release.
