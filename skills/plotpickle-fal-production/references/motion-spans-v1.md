# PlotPickle Motion Spans — provider-neutral v1 (fal implementation)

A Motion Span is a reversible editorial grouping of 1–5 **consecutive** shot addresses within a single Mini-Block. Each nominal 3-second shot is 72 frames at 24 fps, so spans target 72, 144, 216, 288 or 360 editorial frames (3, 6, 9, 12 or 15 seconds). This is not a promise that any fal model produces that native duration. Do not group nonadjacent positions, cross Mini-Block boundaries, silently rewrite a shot's screenplay source, or reserve unplanned shots as completed.

Keep project ID, source revision/raw SHA, ordered storyboard addresses, source passages, first-frame verified media SHA, selected image and Save/Lock evidence, motion/camera cue, duration target, model endpoint, quote/approval record and provider request ID in a separate source-bound sidecar. Absent bytes, approval or model support block execution. One span means at most one explicitly approved paid generation; never automatically fan out 25 credits-consuming calls. Returned files must be retrieved, decoded, hash-verified, then trimmed, split or staged without rewriting story canon. Preserve original source images, approved revisions, and the user review step.
