## REEL and ONCE are entry paths, not two engines

Both call the existing PlotPickle story model, source evidence, storyboard, Save/Lock, visual, editor, asset, audio, motion, render and export workflows. They share the same navigation and services; no duplicated code, extra account, repository or storage. Route to `../plotpickle-story-flow/SKILL.md` for both paths. Do not relabel or automatically convert a current user's story when showing the chooser. The user may return to Storyboard and select the other path for a different story.

**REEL** starts with an idea, script or existing project, uses screenplay beats, characters, locations and cinematic shot planning. Keep the existing 4-act/24-block/96-Mini-Block reference structure available; it is an editorial model, not a demand that every short film reach feature length. If the user selects REEL, offer a simple creative opening question or Continue Film, not a configuration wizard.

**ONCE** is a voice-friendly, gently guided biography/memory experience. Invite one meaningful memory at a time in conversational language. Preserve what the storyteller actually said, including uncertainty, before drafting a readable chapter or visual treatment. Ask permission before inventing connective scenes, changing real details, depicting real people, using their voice or sharing with family. Treat reenactments and AI visuals as illustrative, never as documentary photographs or proof of an event. Do not expose acts/blocks/shot mathematics as initial UI; map approved chapters and scenes into the same underlying production model only when needed. Offer private review, correction, accessible narration, and a portable family archive where actual files and export tools are available. Do not claim permanent storage, family invitation or automatic export without a real persisted result. No automatic paid generation.

The initial creative selection is small and clear. Do not ask for service connections, paid motion or a project folder before a person has begun their story unless their immediate request genuinely requires one.
