## HOME — five equally selectable destinations, canonical order

1. **Meet Elara** — a creative partner in the SAME ChatGPT conversation (ideation, writing, collaboration).
2. **Learn** — canonical 81 lessons / 12 topics; open source-backed lessons.
3. **Storyboard** — REEL or ONCE, both feeding the SAME PPF story engine; source-backed map, 5×5 shot grid, image review, BEAT inspection and six-track editor where supported.
4. **Library / Your Stories** — the signed-in account's **saved private Studio catalogue**; separately label unverified source references, and allow explicit user selection. This is the **fourth sitemap entry**, and makes **five total HOME selections**. `studio_list_projects` is the authoritative list of saved Studio entries; it is NOT an automatic scan of the ChatGPT Library. A quiet `Open ChatGPT Library` link may remain inside this surface. Never auto-open/switch projects.
5. **Connected Services** — PlotPickle Studio, ChatGPT Library, fal, Suno, BUZZ, Modem, with real provider status checks as available and no automatic spending.

## Nested surface map

- **Storyboard** → **REEL** (New Idea / Import Script / Continue Film / Explore Tools), **ONCE** (People / Places / Memories / Illustrations / Preserve), and verified Your Stories → Story Map → Mini-Block 5×5 Shot Grid → Shot Inspector / Image Review → Editor / Production where available.
- **Library / Your Stories** → Verified saved private Studio projects / Source references needing PPF verification / Open user-selected PPF in conversation / Optional ChatGPT Library link. Never equate a source reference with a loadable Studio project.
- **Learn** → 12 topics → 81 real lessons.
- **Meet Elara** → Continue in-chat with Elara.
- **Connected Services** → View source-backed connection state; spending requires explicit job-specific consent.

## HOME composition

Exact source-locked branding, HOME breadcrumb, title “What will you create today?”, one-line subtitle, **five selectable cards** in order, a selected-workspace detail/preview panel, and a quiet status footer. Responsive: two columns on wider screens, one on phones; the fifth card may span the full width on desktop but remains equally operable. Read-only HOME entry. `Home`, `Studio`, `Open Studio HOME`, `Open Studio`, and `/home` are aliases for the SAME interactive in-conversation application. Keep the existing authenticated backend, originals, locked assets and six-track editorial state intact.

## Approval boundaries

This locks the **visual/interaction contract and sitemap**, not untested Site deployment, native ChatGPT Library folder access, native PPF writeback, editor parity, or an actual desktop/phone acceptance result. Changes to this order require the creator's explicit approval and a new numbered specification. Skin V1 remains the historical source for all non-conflicting details, including its approved shot grid, image review, Save/Lock safeguards, and studio provenance distinctions.
