# PlotPickle — Graphic-Novel Mini-Block Edition (v0.8.38)

The owner chose **25 separate shot positions per Mini-Block**, grouped into **five readable pages of five panels each**. Every page has exactly one panel for each consecutively numbered shot. No compression to 15 images. This presentation is a reading edition of the same story, not a change to the 4 Acts × 24 Blocks × 96 Mini-Blocks × 25 planning positions scaffold.

## Reading existing pages

1. Identify the authorized latest story PPF, revision, SHA-256 and exact Act/Block/Mini address; open saved graphic-novel output from the user's accessible Library/Project when available.
2. Check file existence and readable bytes for the PDF or actual five image files before claiming an edition is complete. Link the actual files, not fabricated sandbox paths or thumbnails. Keep the saved story's graphic-novel folder private, never package its images inside the plugin.
3. Present five sequential pages (01–05, 06–10, 11–15, 16–20, 21–25) in reading order, with source-linked captions and dialogue. If metadata says a page exists but the file is unavailable, mark unverified.
4. Preserve the source screenplay and all canonical PPF image Save/Lock decisions unchanged; the graphic novel is a separate edition and cannot prove 25 generated, human-approved or locked production images.

## Preparing additional Mini-Blocks on request

1. Reopen exact screenplay and shot mapping. The first opening Mini-Block may already have 25 authored positions; later Mini-Blocks may have broader scene prose but no shot-by-shot plan. Plan 25 nonduplicative source-linked positions before claiming illustrated coverage. Label creative synthesis or invented framing as proposal, not pre-existing script truth.
2. Keep character likeness, wardrobe, island architecture, time of day, style and recurring props consistent with the creator's selected visual reference. For an original animated film look, do not copy protected characters/artwork from another movie. Note any ambiguity or contradictions in source materials instead of silently changing story canon.
3. Place 5 full illustrations on each page, preserving camera intent and any exact dialogue from source. Use high-legibility typography; avoid truncated text and overlaying dialogue on faces. Validate panel order and shot coverage; do not label a page finished without actual 5 image panels.
4. Save finished PDF plus 5 page-image assets in a project-specific private story folder only when user authorized and the available host file tools support persistence; report returned file references and verify after saving. Never modify canonical PPF, original source screenplay or saved shot assets as a side effect.
5. Proceed through additional pages/Mini-Blocks on explicit creative request and within actual session capabilities. This packaged workflow is not an automated always-on renderer; do not claim completion of a 480-page novel simply because all positions are planned.

A full 24-Block feature yields 96 Mini-Blocks × 5 pages = **480 possible pages**, if every page is actually created. Production clips, editorial timing and approved image lock state remain distinct from comic-page coverage.
